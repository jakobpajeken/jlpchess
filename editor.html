Website-Editor

Partien, Blogposts und Stimmen von Schülern pflegen — ohne Code, von jedem Gerät aus. Jede Speicherung hier wird direkt als Commit in deinem Website-Repository gespeichert und ist innerhalb weniger Sekunden live.

Noch nicht verbunden — Token einfügen, um deine Website zu bearbeiten.
Wie bekomme ich einen Token?
1. Auf GitHub: Einstellungen → Developer settings → Fine-grained tokens → „Generate new token"
2. Repository access: nur jlpchess auswählen (nicht dein ganzes Konto)
3. Permissions → Contents: auf „Read and write" stellen
4. Token erzeugen, kopieren und hier oben einfügen. Er bleibt nur in diesem Browser gespeichert — niemand sonst sieht ihn.
